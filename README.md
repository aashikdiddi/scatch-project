# Scatch - Full-Stack E-Commerce Web Application

A full-stack e-commerce web application built using Node.js, Express.js, MongoDB, and EJS.

## Live Demo

[Visit Scatch Live](https://scatch-project-fju9.onrender.com/)

## Features

- User Registration and Login
- Secure Password Hashing using bcrypt
- JWT-Based Authentication
- User Logout
- Product Management
- Image Upload Functionality
- Flash Notifications
- Custom CSS Styling
- Online Deployment

## Tech Stack

- Frontend: HTML, CSS, EJS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT, bcrypt
- Deployment: Render

## About the Project

Scatch is a full-stack web development project demonstrating backend development, database integration, authentication, and dynamic server-side rendering.

The application is deployed on Render and can be accessed online.
